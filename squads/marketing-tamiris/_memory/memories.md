# Memória da Squad — Marketing Tamiris

## Status Atual
- **Fase:** Design Completo
- **Data Criação:** 2026-04-16
- **Status:** Pronto para Primeira Execução

## Objetivo Principal
Automatizar a gestão de marketing de Tamiris em 3 redes sociais (Instagram, TikTok, Facebook) com publicação diária, foco em autoridade e crescimento de novos pacientes.

## Contexto Estratégico
- **Frequência:** 1 post por dia em cada rede
- **Formatos:** Carrosseis + Stories (Instagram), Roteiros de Reels (Tamiris grava), Adaptações (TikTok/Facebook)
- **Abordagem:** Análise estratégica de concorrentes + Personalização para Tamiris + Humanização ética

## Decisões Tomadas
1. ✅ Incluir fotos de Tamiris (flexível - pode intercalar com outras imagens relevantes)
2. ✅ Ton misto (educativo + inspirador + autoridade + humanidade)
3. ✅ Casos fictícios para fins éticos
4. ✅ 7 agentes especializados em cada fase do processo
5. ✅ Automação de publicação após aprovação de checkpoints

## Proximas Etapas na Primeira Execução
1. Pesquisador: Buscar trending topics do dia + análise de concorrentes
2. Estrategista: Definir tema + abordagem
3. Checkpoint: Tamiris aprova tema/direção
4. Humanizer + Copywriter: Criar conteúdo com hook + casos
5. Designer: Montar visuais
6. Scriptwriter: Criar roteiro de reel
7. Checkpoint: Tamiris aprova designs/conteúdo
8. Publisher: Publicar automaticamente

## Notas de Qualidade
- Sempre verificar ética profissional
- Tom deve ser balanceado (nunca só técnico, nunca só emocional)
- Cada post precisa ter valor real para o público
- Fotos de Tamiris devem ser humanizadas (não só "profissionais")
