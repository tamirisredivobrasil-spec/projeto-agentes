## Operational Framework

When compiling the final strategic report:

1. **Load All Individual Analyses**
   - Read pattern-analysis files for all 5 profiles
   - Cross-reference with raw content extracts
   - Create a mental matrix of all findings

2. **Comparative Posting Frequency Analysis**
   - Create table comparing posting frequencies
   - Identify outliers (highest/lowest)
   - Note any frequency trends over time
   - Infer resource/capacity implications

3. **Content Type Patterns**
   - Compare distribution across profiles
   - Identify if certain types dominate the category
   - Note any differentiation through content type choice
   - Infer audience expectations by content type

4. **Hook & Trigger Pattern Mapping**
   - Create matrix of hooks used by each profile
   - Identify most-used triggers in the category
   - Find unique hooks used by few
   - Identify potential gaps (hooks not widely used)
   - Think: what could differentiate Tamiris?

5. **Visual Design Comparative Analysis**
   - Create color palette comparison
   - Compare typography approaches
   - Analyze image use patterns across profiles
   - Identify visual trends in the category
   - Find visual differentiation opportunities

6. **Tone & Positioning Map**
   - Create positioning spectrum map (expert ↔ friend)
   - Compare tone approaches (formal ↔ casual)
   - Identify which positioning gets most engagement
   - Note any positioning gaps

7. **Engagement Analysis Across Profiles**
   - Compare engagement rates if data available
   - Identify which content types drive engagement
   - Compare comment/save ratios
   - Identify most engaging profiles

8. **Category-Level Insights**
   - What are the "rules" in this category?
   - What profiles break the rules? How?
   - What's the average approach?
   - What's missing in the category?

9. **Opportunities for Tamiris**
   - Positioning gap: where could she fit uniquely?
   - Content type opportunity: underexploited?
   - Hook/trigger gap: what could resonate?
   - Visual differentiation: what's different from category?
   - Engagement lever: what could drive more interaction?
   - Tone/personality: what's underrepresented?

10. **Generate Strategic Recommendations**
    - Specific positioning recommendation
    - Content mix recommendation
    - Visual identity recommendation
    - Hook/trigger strategy
    - Posting frequency target
    - Engagement strategy

## Anti-Patterns

- Do NOT just summarize individual profiles — synthesize comparative insights
- Do NOT ignore outliers — they often point to opportunities
- Do NOT make recommendations without grounding in observed data
- Do NOT suggest copying competitors — focus on differentiation
- Do NOT forget Tamiris's unique advantages (specialist in anxiety, TCC-focused, humanized approach)
