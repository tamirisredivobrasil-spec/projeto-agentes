## ✏️ SE PRECISAR EDITAR

### Mudar Texto de um Slide
```
1. Abra: dia-11_slide-01.html (em editor de texto)
2. Procure o texto que quer mudar
3. Edite direto no HTML
4. Salve o arquivo
5. Renderize novamente: node render_fast.js
6. Novo PNG criado!
```

### Mudar Cor
```
1. Abra qualquer .html
2. Procure no <style> a cor (ex: #D4A5A5)
3. Substitua pelo novo hex
4. Renderize novamente
5. Todos os slides com essa cor mudaram!
```

### Trocar Foto
```
1. Edite generate_posts.js
2. Mude a URL da foto em FOTO_MAPPING
3. Execute: node generate_posts.js
4. Execute: node render_fast.js
5. Pronto!
```
