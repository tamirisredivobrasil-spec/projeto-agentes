## 📞 SUPORTE & CUSTOMIZAÇÕES

Se precisar:

### ✏️ Editar um texto:
1. Abra `dia-XX_slide-YY.html`
2. Procure o texto no HTML
3. Edite direto
4. Execute `node render_fast.js` para gerar novo PNG

### 🎨 Mudar uma cor:
1. Abra qualquer HTML
2. Procure no `<style>` o hex (ex: `#D4A5A5`)
3. Substitua pela cor nova
4. Renderize novamente

### 📸 Trocar uma foto:
1. Edite `generate_posts.js` (seção `FOTO_MAPPING`)
2. Adicione nova URL do Unsplash ou seu servidor
3. Execute `node generate_posts.js` + `node render_fast.js`

### ➕ Adicionar mais posts:
1. Adicione 20 posts novos ao JSON
2. Execute os scripts novamente
3. Pronto! 40 posts em minutos
