## 🔄 Passos para Publicação

### 1️⃣ **Opção A: Meta Business Suite (Recomendado)**

```
1. Acesse: business.facebook.com
2. Vá para: Creator Studio → Posts
3. Clique em: "Criar Carrossel"
4. Faça upload: dia-XX_slide-01.png → dia-XX_slide-0N.png
5. Adicione legenda com CTA (veja abaixo)
6. Agende para melhor horário
7. Publique!
```

### 2️⃣ **Opção B: Agendador Externo**

Use **Buffer**, **Hootsuite**, ou **Later**:
1. Upload das imagens em sequência
2. Escreva a caption
3. Agende data e hora
4. Deixe automático!

### 3️⃣ **Opção C: Publicação Manual**

1. Abra Instagram
2. Clique em "+Criar"
3. Selecione "Carrossel"
4. Faça upload dos slides (dia-XX_slide-01.png, slide-02.png, etc.)
5. Escreva o caption (veja textos abaixo)
6. Publique!

## 🎨 Customizações Possíveis (Se Precisar)

### Editar um Post:
1. Abra o arquivo HTML (ex: `dia-11_slide-01.html`)
2. Edite o texto direto no HTML
3. Salve e converta para PNG (ou compartilhe comigo)

### Mudar cores:
1. Abra qualquer HTML
2. Procure os valores HEX no `<style>`
3. Substitua (ex: `#D4A5A5` por outra cor rosa)

### Adicionar mais informações:
1. Edite o HTML
2. Adicione novos `<p class="text-block">` 
3. Renderize em PNG
