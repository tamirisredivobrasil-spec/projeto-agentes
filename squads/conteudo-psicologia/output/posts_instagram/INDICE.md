## 🎯 COMO USAR OS ARQUIVOS

### Para Publicar (Mais Simples)
```bash
cd posts_instagram/images/
# Selecione os 3 slides do dia 11
# Faça upload no Instagram
# Pronto! 🎉
```

### Para Editar (Se Precisar)
```bash
# 1. Editar HTML
cd posts_instagram/
nano dia-11_slide-01.html  # ou editor favorito

# 2. Renderizar PNG novamente
node render_fast.js

# 3. Upload do PNG novo
cd images/
# Usar nova imagem
```

### Para Criar Mais Posts
```bash
# 1. Adicionar dados ao JSON
nano plano_posts_instagram.json

# 2. Gerar novo HTML
node generate_posts.js

# 3. Renderizar em PNG
node render_fast.js

# 4. Publicar!
```
