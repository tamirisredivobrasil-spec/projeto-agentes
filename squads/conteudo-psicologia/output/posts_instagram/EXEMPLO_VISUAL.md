## ✨ ELEMENTOS ESPECIAIS

### Logo/Branding
```
Texto: @psitamiris.redivo
Posição: Bottom-right
Font: Inter 20px
Color: Rosa suave (#D4A5A5) ou Chocolate
Contrast: WCAG AA ✅
```

### Destaque (Highlight)
```
Classe: .hl
Color: Rose Suave (#D4A5A5)
Weight: Bold 700
Uso: Palavras-chave importantes
Exemplo: "modo alerta"
```

### Espaçamento
```
Content Margin: 72px (5% do viewport)
Section Gap: 48px (entre blocos)
Line Gap: 16px (entre linhas)
Breathing room: Amplo (elegância)
```
